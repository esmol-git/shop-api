# ADR 0002: Временные метки товара

## Контекст

У `StockMovement` есть `createdAt` операции, но у `Product` не было ни
даты создания, ни даты изменения. Без них нельзя отличать «когда завёл
карточку» от «когда последний раз трогали запись».

Остаток лежит в строке `products`, поэтому нужно явно решить: двигает ли
приход/списание `updatedAt`.

## Решение

| Поле | Смысл |
|---|---|
| `createdAt` | момент создания товара; не меняется |
| `updatedAt` | любое изменение строки товара: карточка, остаток, учёт, архивация |
| `archivedAt` | момент архивации; `null` — активен (см. ADR 0001) |

`updatedAt` — только время последнего изменения, не журнал истории.

## Последствия

- В API товар отдаёт `createdAt` / `updatedAt` как ISO-8601.
- Складские команды через `updateMany` тоже обновляют `updatedAt`.
- Повтор архивации и точный повтор идемпотентной операции не обязаны
  двигать `updatedAt`, если строка товара не менялась.
